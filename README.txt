BELFAST KANNADA BALAGA WEBSITE

This folder is ready to deploy as a static website.

CLOUDFLARE PAGES (no Docker, no build tools required)
1. Create a GitHub repository and upload index.html.
2. In Cloudflare go to Workers & Pages > Create > Pages > Connect to Git.
3. Select the repository.
4. Framework preset: None.
5. Build command: leave blank.
6. Build output directory: /
7. Deploy.
8. In Custom Domains, add your domain.

You can also use Cloudflare Pages Direct Upload and upload this folder.

Main file: index.html
